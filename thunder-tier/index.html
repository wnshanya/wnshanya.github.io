ПРОДОЛЖИШЬ С ТОГО ЖЕ МЕСТА

Твоя сессия

Расстановка, порядок карточек, подписи тиров и аватарки сохраняются автоматически в этом браузере.

Чтобы продолжить на другом компьютере или сохранить несколько вариантов рейтинга, скачай файл сессии. В нём есть все аватарки. При очистке данных браузера автосохранение может пропасть; файл останется у тебя.

Загрузка заменит текущую расстановку. После загрузки её можно вернуть кнопкой «Отменить». Старые файлы проектов тоже поддерживаются.

ИСХОДНЫЙ ТИР-ЛИСТ

Начать заново?

Все исходные участники вернутся в резерв, включая удалённых. Расстановка, заголовок и подписи тиров сбросятся. Добавленные тобой карточки будут убраны.

Сброс затронет только этот браузер. При желании сначала скачай текущую сессию. Сразу после сброса его можно отменить кнопкой «Отменить».
