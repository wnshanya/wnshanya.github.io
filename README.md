# wnshanya.github.io

Личный сайт на GitHub Pages: Thunder Tier для сообщества War Thunder.

## ⚡ Thunder Tier — блогеры и стримеры War Thunder

**[Открыть тир-лист →](https://wnshanya.github.io/thunder-tier/)**

Расставь знакомых авторов по тирам S–D и поделись результатом. В стартовом наборе — **42 участника** с аватарками каналов. Оценки выставляешь ты: при первом открытии все карточки находятся в резерве.

### Что умеет сайт

- Перетаскивание карточек между тирами и изменение их порядка внутри ряда.
- Добавление своих авторов, замена аватарок и переименование тиров.
- Режим записи ролика без служебных кнопок — клавиша **R**.
- Автосохранение текущей расстановки в браузере.
- Скачивание и загрузка файлов сессий со всеми аватарками.
- Экспорт PNG шириной **1920 или 3840 пикселей**, с резервом или без него.

### У каждого — свой рейтинг

Регистрация не нужна. Расстановка хранится **только в браузере посетителя на его устройстве** и не отправляется в этот репозиторий. Друзья могут пользоваться одним адресом сайта и составлять независимые рейтинги.

Для сохранения нескольких вариантов или переноса на другой компьютер используй **«Сессия → Скачать сессию»**, затем **«Загрузить сессию»**. При очистке данных браузера автосохранение может пропасть — скачанный файл сессии позволяет восстановить рейтинг.

### Файлы проекта

Исходники тир-листа находятся в [`thunder-tier/`](thunder-tier/): HTML, CSS и JavaScript без серверной части и без установки зависимостей. Аватарки встроены в `roster.js` и доступны без обращения к Twitch или YouTube.

Для локального запуска скачай папку проекта и открой `index.html` в современном браузере. Дополнительные инструкции — в [README тир-листа](thunder-tier/README.md).
