# Thunder Tier

**[Открыть тир-лист](https://wnshanya.github.io/thunder-tier/)** · 42 участника · War Thunder

Тир-лист блогеров и стримеров War Thunder: перетаскивание карточек, свои участники, режим записи, сессии и экспорт PNG.

## Пользователям

- Перетащи участника из резерва в тир S–D. Порядок внутри рядов тоже можно менять.
- Рейтинг автоматически сохраняется **в твоём браузере на этом устройстве**. У каждого посетителя своя расстановка. Регистрация не нужна.
- Кнопка **«Сессия»** позволяет скачать рейтинг в JSON со всеми аватарками или загрузить ранее сохранённый файл. Так можно хранить несколько вариантов и переносить их между устройствами.
- **«Сохранить PNG»** создаёт картинку шириной 1920 или 3840 пикселей, с резервом или без него.
- **R** включает режим записи; **F11** включает полный экран браузера.
- Двойной щелчок по карточке открывает её настройки.

Расстановки, загруженные пользователем картинки и сессии не отправляются на сервер. Автосохранение привязано к браузеру и адресу сайта: при очистке данных браузера, в приватном режиме или при смене адреса оно может быть недоступно. Для надёжного хранения скачай JSON-файл сессии. При переходе с локального файла на опубликованный сайт сначала скачай сессию в локальной версии, затем загрузи её на сайте.

## GitHub Pages

Это статический сайт без сборки и серверной части. Все аватарки встроены в `roster.js`; отдельная папка с картинками не нужна.

1. Создай репозиторий и помести файлы этого каталога в корень ветки `main`.
2. Открой **Settings → Pages → Build and deployment**.
3. Выбери **Deploy from a branch**, ветку **main**, каталог **/ (root)** и нажми **Save**.
4. После публикации GitHub покажет адрес сайта. Поделись этим адресом с друзьями.

При бесплатном плане GitHub для Pages используется публичный репозиторий. Не добавляй в репозиторий свои JSON-файлы сессий — сайт сохраняет их у пользователей локально.

## Состав файлов

- `index.html` — страница и окна настроек.
- `style.css` — оформление.
- `app.js` — перетаскивание, автосохранение и файлы сессий.
- `export.js` — экспорт PNG.
- `roster.js` — стартовый набор из 42 участников со встроенными аватарками.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

Ссылки на каналы доступны внутри сайта. Сайт является самостоятельным фанатским проектом; названия и аватарки каналов принадлежат их владельцам.

## Автор и поддержка

Проект создан [WNSHANYA](https://www.twitch.tv/wnshanya). [Поддержать развитие проекта](https://www.donationalerts.com/r/wnshanya).

В обычном режиме карточка автора выделена золотистой рамкой и меткой «АВТОР». В режиме записи оформление карточки становится обычным, а блок автора и поддержки скрывается. В PNG эти элементы также не включаются.

Кнопка **«Сбросить всё»** восстанавливает исходных участников, включая удалённых, и возвращает их в резерв. Она сбрасывает только сессию в текущем браузере; перед подтверждением можно скачать её копию.
